## Properti Notion Direkomendasikan

Buat database Notion dengan properti berikut agar tabel di atas dapat diimpor atau diketik ulang dengan benar:

| Nama Properti | Tipe Notion  | Opsi / Contoh                                                                                                                  | Keterangan                             |
| ------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| Fitur         | Title        | —                                                                                                                              | Nama fitur utama                       |
| Paket         | Select       | @hudbird/ui, @hudbird/marketing, @hudbird/theme, @hudbird/schemas, hudbird-ui, apps/docs, starter-kits                         | Paket tempat fitur berada              |
| Kategori      | Multi-select | UI Primitive, Marketing Block, Signature Block, Glassmorphism, Design System, Schemas, Templates, CLI, Dokumentasi, AI Tooling | Boleh lebih dari satu                  |
| Status        | Status       | ✅ Rilis, 🟡 Pengembangan, 🔴 Rencana, ⏸️ Tertunda, 🗑️ Dihentikan                                                              | Gunakan Notion Status property         |
| Prioritas     | Select       | P0 (Critical), P1 (High), P2 (Medium), P3 (Low)                                                                                | Urutan pengerjaan                      |
| Owner         | Person       | Frontend, Marketing, Core, Design, Docs, AI, Product                                                                           | Siapa yang bertanggung jawab           |
| Target Rilis  | Date         | v1.5.0, v1.6.0, v2.0.0                                                                                                         | Target versi rilis                     |
| Catatan       | Text         | —                                                                                                                              | Catatan teknis atau catatan peluncuran |

## Panduan Status Fitur (Best Practice Manajemen)

Guna memahami status fitur dan mengelola roadmap Hudbird UI Pro, gunakan definisi status berikut secara konsisten di semua database Notion.

| Status              | Emoji | Definisi                                                          | Kriteria Keluar (Exit Criteria)                                                                                                                                                    | Tindakan Selanjutnya                                                                      |
| ------------------- | ----- | ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **✅ Rilis**        | ✅    | Fitur telah dirilis dan tersedia untuk produksi.                  | - Kode telah di-merge ke branch utama<br>- Lolos uji tipe TypeScript (`tsc --noEmit`)<br>- Ada contoh kode di dokumentasi (`apps/docs`)<br>- Accessibility dicek (keyboard + ARIA) | Pantau laporan bug, kumpulkan feedback pengguna, rencanakan perbaikan di versi berikutnya |
| **🟡 Pengembangan** | 🟡    | Fitur sedang dalam pengembangan aktif.                            | - Kode masih di branch fitur (belum merge)<br>- Belum lolos semua uji tipe atau aksesibilitas<br>- Belum ada dokumentasi resmi                                                     | Selesaikan implementasi, tulis tes, dokumentasikan, lalu pindah ke Rilis                  |
| **🔴 Rencana**      | 🔴    | Fitur telah dijadwalkan tetapi belum dimulai.                     | - Belum ada kode yang ditulis<br>- Belum ada desain atau spesifikasi teknis                                                                                                        | Buat spesifikasi, alokasikan penanggung jawab, tentukan target rilis                      |
| **⏸️ Tertunda**     | ⏸️    | Fitur ditunda sementara karena dependensi atau prioritas berubah. | - Alasan penundaan telah dicatat di kolom Catatan<br>- Pihak terkesi setuju dengan penundaan                                                                                       | Tinjau kembali setiap sprint, aktifkan kembali atau batalkan                              |
| **🗑️ Dihentikan**   | 🗑️    | Fitur tidak akan dilanjutkan atau sudah diganti.                  | - Alasan pencabutan dicatat<br>- Pengguna diinformasikan (jika ada yang sudah memakai)                                                                                             | Arsipkan dokumentasi, hilangkan dari daftar aktif, hindari penggunaan baru                |

## Alur Kerja (Workflow) Direkomendasikan

1. **Rencana** → Buat entri di database Notion dengan status `🔴 Rencana`, tentukan Owner dan Prioritas.
2. **Pengembangan** → Pindah ke `🟡 Pengembangan` saat pengembang mulai bekerja. Buat branch fitur di Git.
3. **Review & QA** → Sebelum pindah ke Rilis, pastikan:
   - TypeScript tidak error (`tsc --noEmit` bersih untuk fitur tersebut)
   - Komponen accessible (keyboard navigation, ARIA labels)
   - Contoh kode tersedia di `apps/docs`
4. **Rilis** → Pindah ke `✅ Rilis` setelah di-merge ke branch utama dan dokumentasi dipublikasikan.
5. **Pantauan** → Kumpulkan bug dan feedback. Jika fitur tidak lagi dipakai, pindah ke `🗑️ Dihentikan`.

## Tips Paste ke Notion

1. Salin seluruh tabel di atas (mulai dari baris header sampai baris terakhir).
2. Buka halaman Notion, ketik `/table` dan pilih **Table – Full page** atau **Table – Inline**.
3. Tempelkan tabel. Notion akan otomatis membuat kolom dari baris pertama (header).
4. Sesuaikan tipe properti sesuai tabel "Properti Notion Direkomendasikan" di atas (ubah kolom Status menjadi properti Status bawaan Notion, dll.).
5. Tambahkan tampilan (View) tambahan seperti:
   - **Board** dikelompokkan oleh Status (untuk melihat pipeline fitur)
   - **Board** dikelompokkan oleh Paket (untuk melihat progres per paket)
   - **Timeline** berdasarkan Target Rilis (untuk roadmap visual)
