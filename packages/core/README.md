# @hudbird/ui

> A modern, beautiful, and highly customizable React UI library built with Tailwind CSS and Framer Motion.

Hudbird UI is designed to give you **Copy-Paste Readiness**. It provides a set of meticulously crafted components that you can drop directly into your React applications, packed with micro-interactions and smooth animations.

## 🚀 Quick Start

The easiest way to get started is by using our CLI tool. In your React + Tailwind project, simply run:

```bash
npx hudbird-ui@latest init
```

If you prefer manual installation, you can install the core package:

```bash
npm install @hudbird/ui
```

## ✨ Features

- 🎨 **Beautiful by Default**: Meticulously crafted design system.
- ⚡ **Powered by Tailwind CSS**: Zero custom CSS files, 100% utility classes.
- 🎬 **Fluid Animations**: Built-in micro-interactions powered by Framer Motion.
- 🧩 **Accessible**: Built with semantic HTML and accessibility in mind.
- 🌙 **Dark Mode Ready**: Every component looks great in light and dark environments out of the box.
