# hudbird-ui

> The official CLI for initializing and scaffolding components in Hudbird UI.

Hudbird UI is a modern, beautiful React UI library built with Tailwind CSS and Framer Motion. This CLI tool helps you set up your project and add components with zero friction.

## 🚀 Usage

You don't need to install the CLI globally. You can run it directly using `npx`:

```bash
npx hudbird-ui@latest init
```

### Commands

#### `init`

Initializes Hudbird UI in your current React + Tailwind project. It will:

- Install required dependencies (`@hudbird/ui`, `lucide-react`, `framer-motion`, etc.)
- Set up your Tailwind configuration automatically
- Wrap your app with the required Theme Providers
