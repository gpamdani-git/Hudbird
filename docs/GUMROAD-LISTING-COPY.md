### ❓ Frequently Asked Questions (FAQ)

**Q: Can I use components from this monorepo in my Next.js project?**  
A: Yes! All components use standard React + Tailwind CSS + Framer Motion. You can easily copy and paste any component or section directly into Next.js (App Router or Pages Router) or Vite.

**Q: Do I need an active NPM token or account to use this?**  
A: No! The monorepo is 100% standalone and self-contained. All packages link locally via `workspace:*`, meaning you can build and run everything offline without touching the NPM registry.

**Q: Will I get updates?**  
A: Yes. All customers receive lifetime access to future v1.x additions and template releases through their Gumroad library.

**Q: What package manager is required?**  
A: We recommend **PNPM** (v9+) for the best monorepo workspace experience. You can enable it in seconds via `corepack enable pnpm`.
